# Fais mes classes

Application web JavaScript simple pour regrouper des élèves en classes avec contraintes.

## Étapes

1. Importer deux CSV qui contiennent les données des élèves et des contraintes.
2. Lancer le regroupement.
3. Exporter le CSV résultat ou copier le tableau pour le coller dans un tableur.

L'importance donnée à chaque contrainte par l'algorithme d’optimisation peut être réglée.
